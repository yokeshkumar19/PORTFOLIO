# YK. — Personal Portfolio

The personal design and engineering portfolio of **YK.** — Student, Designer & Developer.

Built with a high-impact dark aesthetic, bold oversized typography, vivid orange accents (`#FF5A1F`), fluid responsive layouts, and silky smooth motion choreography.

## 🚀 Commands

### Development Server
```bash
npm run dev
```
Accessible locally at [http://localhost:3000](http://localhost:3000) and on your Wi-Fi network at `http://<your-local-ip>:3000`.

### Production Build
```bash
npm run build
```
Generates an optimized static bundle in `dist/`.

### Preview Production Build
```bash
npm run preview
```
